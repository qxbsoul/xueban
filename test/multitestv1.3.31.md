### 8.1 平方根

#### 8.1.1 平方根的概念与求法

> 已知一个数，通过平方运算可以求这个数的平方。反过来，如果已知一个数的平方，怎样求这个数呢？例如，如果一个数的平方等于9，这个数是多少？

##### 平方根的概念

如果一个数的平方等于9，因为 \(3^2=9\)，所以这个数可以是3；又因为 \((-3)^2=9\)，所以这个数也可以是-3。除3，-3以外，任何一个数的平方都不等于9。因此，如果一个数的平方等于9，那么这个数是3或-3。

一般地，\(\pm 3\) 的平方等于9，9的平方根是 \(\pm 3\)。可以发现，平方与开平方互为逆运算。根据这种互逆关系，可以求一个数的平方根。

##### 求一个数的平方根

求一个数的平方根，就是寻找平方等于这个数的数。例如：
- 因为 \((\pm 8)^2=64\)，所以64的平方根是 \(\pm 8\)；
- 因为 \((\pm 0.1)^2=0.01\)，所以0.01的平方根是 \(\pm 0.1\)。

判断一个数是否有平方根时，需要先判断该数是正数、0还是负数：正数有两个平方根，负数没有平方根。

**例题**

题目：求下列各数的平方根：(1) 64；(2) 0.01。

思考提示：根据平方与开平方互为逆运算，寻找平方等于该数的数。


```answer
1. 因为 \((\pm 8)^2=64\)，所以64的平方根是 \(\pm 8\)。
   依据：平方等于64的数是8和-8。
2. 因为 \((\pm 0.1)^2=0.01\)，所以0.01的平方根是 \(\pm 0.1\)。
   依据：平方等于0.01的数是0.1和-0.1。

答案：64的平方根是 \(\pm 8\)；0.01的平方根是 \(\pm 0.1\)。

易错提醒：正数的平方根有两个，不要漏掉负的平方根。
```

**易错点**

- 认为一个正数只有一个平方根，漏掉负的平方根。
- 认为负数也有平方根。

**理解检查**

1. 因为 \((\pm 8)^2=64\)，所以64的平方根是什么？

```check-answer
参考答案：\(\pm 8\)
```

```check-answer
参考答案：\(\pm 0.1\)
```

**本单元小结**

平方根是平方等于该数的数；平方与开平方互为逆运算，可据此求平方根；正数有两个平方根，负数没有平方根。

#### 8.1.2 平方根的性质与符号表示

> 正数的平方根有什么特点？0的平方根是多少？负数有平方根吗？

##### 正数、0、负数的平方根的特点

正数有两个平方根，它们互为相反数。

因为 \(0^2=0\)，并且任何一个不为0的数的平方都不等于0，所以0的平方根是0。

正数的平方是正数，负数的平方也是正数，0的平方是0，即在我们所认识的数中，任何一个数的平方都不是负数，所以负数没有平方根。

##### 平方根的符号表示

正数 \(a\) 的正的平方根记为 \(\sqrt{a}\)，读作“根号 \(a\)”，\(a\) 叫作被开方数；正数 \(a\) 的负的平方根可以用 \(-\sqrt{a}\) 表示，故正数 \(a\) 的平方根可以用“\(\pm\sqrt{a}\)”表示，读作“正、负根号 \(a\)”。例如，\(\pm\sqrt{9}\) 表示9的平方根，\(\pm\sqrt{9}=\pm 3\)。特别地，0的平方根记为 \(\sqrt{0}\)。

只有当 \(a\) 大于或等于0时，\(\sqrt{a}\) 有意义；而当 \(a\) 小于0时，\(\sqrt{a}\) 没有意义。

**例题**

题目：下列各数有平方根吗？如果有，求它的平方根；如果没有，说明理由。(1) 0.36；(2) -5；(3) \((-4)^2\)。

思考提示：先判断该数是正数、0还是负数，再根据平方根的特点求平方根。


```answer
1. 因为0.36是正数，所以0.36有两个平方根，\(\pm\sqrt{0.36}=\pm 0.6\)。
   依据：正数有两个平方根，它们互为相反数。
2. 因为-5是负数，所以-5没有平方根。
   依据：负数没有平方根。
3. 因为 \((-4)^2=16\) 是正数，所以 \((-4)^2\) 有两个平方根，\(\pm\sqrt{(-4)^2}=\pm\sqrt{16}=\pm 4\)。
   依据：先化简 \((-4)^2=16\)，再判断16是正数，有两个平方根。

答案：(1) 0.36的平方根是 \(\pm 0.6\)；(2) -5没有平方根；(3) \((-4)^2\) 的平方根是 \(\pm 4\)。

易错提醒：判断一个数是否有平方根，要看化简后的数，如 \((-4)^2=16\) 是正数，有平方根。
```

- 认为负数有平方根。
- 认为0没有平方根。


2. 0的平方根是多少？

```check-answer
参考答案：0的平方根是0。
```

```check-answer

```

**本单元小结**

正数有两个互为相反数的平方根，0的平方根是0，负数没有平方根；正数 \(a\) 的平方根表示为 \(\pm\sqrt{a}\)，\(\sqrt{a}\) 中 \(a\ge 0\)。

#### 8.1.3 算术平方根的概念与求法

> 正数 \(a\) 有两个平方根，其中正的平方根 \(\sqrt{a}\) 叫作 \(a\) 的算术平方根。

##### 算术平方根的概念

正数 \(a\) 有两个平方根，其中正的平方根 \(\sqrt{a}\) 叫作 \(a\) 的算术平方根。正数 \(a\) 的算术平方根用 \(\sqrt{a}\) 来表示。

规定：0的算术平方根是0，0的算术平方根也记为 \(\sqrt{0}\)。

**平方根与算术平方根的区别与联系**：正数 \(a\) 的平方根有两个，表示为 \(\pm\sqrt{a}\)，它们互为相反数；算术平方根只取非负的那个，表示为 \(\sqrt{a}\)。例如，9的平方根是 \(\pm 3\)，9的算术平方根是3。

##### 求算术平方根

根据算术平方根的定义，可以求一个正数的算术平方根。例如：
- 因为 \(10^2=100\)，所以100的算术平方根是10，即 \(\sqrt{100}=10\)；
- 因为 \(0.01^2=0.0001\)，所以0.0001的算术平方根是0.01，即 \(\sqrt{0.0001}=0.01\)。

从例3可以看出：被开方数越大，对应的算术平方根就越大。这个结论对所有正数都成立。

#### 8.1.4 用计算器求算术平方根与估算

> 怎样用两个面积为1dm²的小正方形拼成一个面积为2dm²的大正方形？这个大正方形的边长是多少？

##### 用计算器求算术平方根

大多数计算器都有平方根键，用它可以求出一个正有理数的算术平方根（或其近似值）。不同品牌的计算器，按键顺序有所不同。

通过平方运算可以估计算术平方根的范围。例如，因为 \(1^2=1\)，\(2^2=4\)，\(1^2<2<2^2\)，所以 \(1<\sqrt{2}<2\)；继续用同样方法可得 \(1.4<\sqrt{2}<1.5\)，\(1.41<\sqrt{2}<1.42\)，\(1.414<\sqrt{2}<1.415\) 等。

```answer
易错提醒：取近似值时注意题目要求保留的小数位数，不要随意多写或少写。
```

**易错点**

- 认为 \(\sqrt{2}\) 是有限小数。

### 8.2 立方根

#### 8.2.1 立方根与开立方的概念及正负零的立方根特点

> 上一节我们通过研究平方的逆运算学习了平方根，本节来研究立方的逆运算。如果一个数的立方等于8，那么这个数是多少？

##### 立方根的概念
一般地，如果一个数 \(x\) 的立方等于 \(a\)，即 \(x^3=a\)，那么这个数 \(x\) 叫作 \(a\) 的立方根或三次方根。例如，因为 \(2^3=8\)，所以2是8的立方根。求一个数的立方根的运算，叫作开立方。

##### 开立方与立方的关系
正如开平方与平方互为逆运算一样，开立方与立方也互为逆运算。根据这种互逆关系，可以求一个数的立方根。

##### 正数、负数、0的立方根特点
通过填空：因为 \(1^3=1\)，所以1的立方根是1；因为 \(0.4^3=0.064\)，所以0.064的立方根是0.4；因为 \((-2)^3=-8\)，所以-8的立方根是-2；因为 \((-\frac{1}{2})^3=-\frac{1}{8}\)，所以 \(-\frac{1}{8}\) 的立方根是 \(-\frac{1}{2}\)；因为 \(0^3=0\)，所以0的立方根是0。归纳得到：正数的立方根是正数，负数的立方根是负数，0的立方根是0。

##### 为什么负数有立方根
负数的立方仍是负数，所以立方运算可以对负数进行，负数有立方根。这与“负数没有平方根”不同：任何数的平方都不是负数，所以负数没有平方根；但负数的立方是负数，所以负数有立方根。

**例题**

题目：根据立方根的意义填空：因为 \((-2)^3=-8\)，所以-8的立方根是（ ）。

思考提示：利用立方与开立方互为逆运算，寻找一个数，使它的立方等于-8。


```answer
1. 因为 \((-2)^3=-8\)，所以-8的立方根是-2。
   依据：根据立方根的定义，若 \(x^3=a\)，则 \(x\) 是 \(a\) 的立方根。

答案：-2

易错提醒：不要误认为负数没有立方根；负数的立方根是负数。
```

**易错点**

- 误认为负数没有立方根，实际上负数的立方根是负数。
- 将开立方与开平方混淆，误以为一个正数的立方根有两个。

**理解检查**

1. 因为 \(0.4^3=0.064\)，所以0.064的立方根是多少？

```check-answer
参考答案：0.4
```

2. 0的立方根是多少？

```check-answer
参考答案：0
```

**本单元小结**

立方根是立方运算的逆运算结果；正数的立方根是正数，负数的立方根是负数，0的立方根是0；开立方与立方互为逆运算。

#### 8.2.2 立方根的符号表示与求一个数的立方根

> 类似于平方根，一个数 \(a\) 的立方根记为 \(\sqrt[3]{a}\)，读作“三次根号 \(a\)”。

##### 立方根的符号表示
一个数 \(a\) 的立方根记为 \(\sqrt[3]{a}\)，读作“三次根号 \(a\)”，其中 \(a\) 是被开方数，3是根指数。例如，\(\sqrt[3]{8}\) 表示8的立方根，\(\sqrt[3]{8}=2\)；\(\sqrt[3]{-8}\) 表示-8的立方根，\(\sqrt[3]{-8}=-2\)。\(\sqrt[3]{a}\) 中的根指数“3”不能省略。

##### 求一个数的立方根
利用开立方与立方的关系求立方根。例如，因为 \(7^3=343\)，所以343的立方根是7，即 \(\sqrt[3]{343}=7\)；因为 \((-4)^3=-64\)，所以-64的立方根是-4，即 \(\sqrt[3]{-64}=-4\)。

##### 与平方根符号的对比
平方根符号 \(\sqrt{a}\) 中根指数2通常省略，且 \(\sqrt{a}\) 表示算术平方根（非负）；而立方根符号 \(\sqrt[3]{a}\) 中根指数3不能省略，且 \(\sqrt[3]{a}\) 表示 \(a\) 的立方根，结果可以是负数。

**例题**

题目：求下列各数的立方根：(1) \((-2)^3\)；(2) 343；(3) -64；(4) \(\frac{125}{27}\)。

思考提示：利用立方运算与开立方互为逆运算，寻找立方等于被开方数的数。


```answer
1. 因为 \((-2)^3=-8\)，所以 \((-2)^3\) 的立方根是-2，即 \(\sqrt[3]{(-2)^3}=-2\)。
   依据：根据立方根定义，\(x^3=a\) 则 \(x\) 是 \(a\) 的立方根。
2. 因为 \(7^3=343\)，所以343的立方根是7，即 \(\sqrt[3]{343}=7\)。
   依据：利用立方运算与开立方互为逆运算。
3. 因为 \((-4)^3=-64\)，所以-64的立方根是-4，即 \(\sqrt[3]{-64}=-4\)。
   依据：负数的立方根是负数。
4. 因为 \((\frac{5}{3})^3=\frac{125}{27}\)，所以 \(\frac{125}{27}\) 的立方根是 \(\frac{5}{3}\)，即 \(\sqrt[3]{\frac{125}{27}}=\frac{5}{3}\)。
   依据：根据立方根定义。

答案：(1) -2；(2) 7；(3) -4；(4) \(\frac{5}{3}\)。

易错提醒：注意根指数3不能省略；求负数的立方根时结果应为负数。
```

**易错点**

- 在书写立方根时省略根指数3，写成 \(\sqrt{a}\)，与平方根混淆。
- 求负数的立方根时误写为正数。

**理解检查**

1. 因为 \(7^3=343\)，所以343的立方根是多少？

```check-answer
参考答案：7
```

2. \(\sqrt[3]{-64}\) 等于多少？

```check-answer
参考答案：-4
```

**本单元小结**

立方根用 \(\sqrt[3]{a}\) 表示，根指数3不能省略；求一个数的立方根就是寻找立方等于该数的数，可利用开立方与立方互为逆运算。

### 8.3 实数及其简单运算

#### 8.3.1 无理数的概念与有理数的关系

> 在前面的学习中，我们通过引入负数，使数的范围扩充到有理数。本章我们认识了像√2，3√3这样的无限不循环小数，它们是有理数吗？如果不是，我们将再次扩充数的范围。

##### 有理数的小数形式
把下列有理数写成小数的形式：4，5/2，-3/5，27/4，11/9，9/11。
可以发现：4=4.0，5/2=2.5，-3/5=-0.6，27/4=6.75，11/9=1.2·，9/11=0.8·1·。
事实上，任何一个有理数都可以写成有限小数或无限循环小数的形式；反过来，任何有限小数或无限循环小数也都是有理数。

##### 无理数的概念
很多数的平方根、立方根是无限不循环小数，例如√2，-√5，3√2，3√3等。π=3.14159265…也是无限不循环小数。
从上面的讨论可知，无限不循环小数都不是有理数。无限不循环小数又叫作无理数。无理数是不能写成两个整数之比（分数）的数。

##### 正无理数与负无理数
像有理数一样，无理数也有正负之分。例如，√2，3√3，π是正无理数，-√2，-3√3，-π是负无理数。

**例题**

题目：把下列有理数写成小数的形式，你发现了什么？4，5/2，-3/5，27/4，11/9，9/11。

思考提示：通过实际计算，观察这些有理数化成小数后的形式，归纳有理数与小数形式的关系。


```answer
1. 4=4.0，5/2=2.5，-3/5=-0.6，27/4=6.75
   依据：这些是有限小数，整数可以写成小数点后为0的小数。
2. 11/9=1.2·，9/11=0.8·1·
   依据：这些是无限循环小数。
3. 归纳：任何一个有理数都可以写成有限小数或无限循环小数的形式；反过来，任何有限小数或无限循环小数也都是有理数。
   依据：由具体例子推广到一般结论。

答案：有理数都可以写成有限小数或无限循环小数的形式；有限小数或无限循环小数也都是有理数。

易错提醒：无限不循环小数不是有理数，不能写成两个整数之比。
```

- 误认为无限小数都是无理数，实际上无限循环小数是有理数，只有无限不循环小数才是无理数。
- 误认为π是无理数所以它不能参与运算，实际上无理数可以像有理数一样进行运算。

#### 8.3.2 实数的概念、分类与数轴表示

> 与有理数可以用数轴上的点表示类似，无理数也可以用数轴上的点表示。下面我们以π，√2，-√2为例，看一看如何在数轴上表示无理数。

##### 实数的概念与分类
有理数和无理数统称实数。这样，我们学过的数可以按定义分类：
实数分为有理数和无理数；有理数包括有限小数或无限循环小数，无理数包括无限不循环小数。
由于非0有理数和无理数都有正负之分，所以非0实数也有正负之分，于是实数也可以按正负性分类：正实数、0、负实数。

##### 实数与数轴
与有理数可以用数轴上的点表示类似，无理数也可以用数轴上的点表示。数轴上表示正无理数a的点在数轴的正半轴上，与原点的距离是a个单位长度；表示负无理数-b（b>0）的点在数轴的负半轴上，与原点的距离是b个单位长度。
例如，以单位长度为直径画一个圆，它的周长等于π。从原点开始，将这个圆沿数轴向右滚动一周，圆上的一点由原点O到达点O′，点O′对应的数就是π。
又如，以单位长度为边长画正方形，以原点为圆心、对角线长为半径画弧，可以在数轴上表示√2和-√2。

#### 8.3.3 实数的相反数与绝对值

> 有理数关于相反数和绝对值的意义同样适用于实数。

##### 实数的相反数
一般地，对于实数，同样有数a的相反数是-a。求一个实数的相反数，只需在这个数前面加上负号。例如，-√6的相反数是√6，π-3.14的相反数是-(π-3.14)=3.14-π。

##### 实数的绝对值
一个实数的绝对值就是它在数轴上的对应点与原点的距离。一个正实数的绝对值是它本身；一个负实数的绝对值是它的相反数；0的绝对值是0。即设a表示一个实数，则
$$|a|=\begin{cases}a, & \text{当 } a>0 \text{ 时}; \\ 0, & \text{当 } a=0 \text{ 时}; \\ -a, & \text{当 } a<0 \text{ 时}.\end{cases}$$
例如，|√2|=√2，|-π|=π，|0|=0。

**例题**

#### 8.3.4 实数的运算与近似计算

> 实数之间不仅可以进行加、减、乘、除（除数不为0）、乘方运算，而且正数及0可以进行开平方运算，任意一个实数可以进行开立方运算。

##### 实数的运算
实数之间不仅可以进行加、减、乘、除（除数不为0）、乘方运算，而且正数及0可以进行开平方运算，任意一个实数可以进行开立方运算。在进行实数的运算时，有理数的运算法则及运算性质等同样适用。
例如，计算(√3+√2)-√2时，可以利用加法结合律：
(√3+√2)-√2=√3+(√2-√2)=√3+0=√3。
计算3√3+2√3时，可以利用分配律：
3√3+2√3=(3+2)√3=5√3。

##### 实数运算的近似计算
在实数运算中，当遇到无理数并且需要求出计算结果的近似值时，一般先用近似有限小数（例如，比计算结果要求的精确度多取一位）去代替无理数，再进行计算，最后对计算结果四舍五入。
例如，计算√5-√7（结果保留小数点后两位）：
√5-√7≈2.236-2.646=-0.41。
在近似计算时，计算过程中有时也使用“去尾法”，即用近似有限小数去代替无理数时，直接舍去要保留数位的下一位数字，最后对计算结果四舍五入。如√5-√7≈2.236-2.645≈-0.41。

### 11.1 不等式

#### 11.1.1 从不等关系到不等式：概念与表示

> 前面我们学习了用等式表示问题中的相等关系，本节我们将学习不等式及其性质。有了不等式，就可以表示问题中的不等关系了。

##### 为什么需要不等式

实际问题中，两个量之间不一定相等，常常需要表示“不到”“超过”等不等关系。例如汽车要在8:00之前驶过A地，从时间上看，行驶210 km的时间不到2 h，可以表示为 $\frac{210}{x}<2$；从路程上看，2 h行驶的路程要超过210 km，可以表示为 $2x>210$。

##### 不等式的含义

像 $\frac{210}{x}<2$、$2x>210$ 这样用符号“<”或“>”表示不等关系的式子，叫作不等式。像 $a+2\neq a-2$ 这样用“≠”表示不等关系的式子也是不等式。

不等式中可以不含字母，例如 $3<4$，$-1>-2$；也可以含有字母，例如上面的 $\frac{210}{x}<2$ 和 $2x>210$。

##### 用不等式表示不等关系的方法

先设未知数，再根据题意找出不等关系，最后列出不等式。例如：
- $a$ 与15的和大于27，表示为 $a+15>27$；
- $b$ 的一半与3的差是负数，表示为 $\frac{b}{2}-3<0$；
- 种植面积1333 hm²超过全县原有猕猴桃种植面积的18倍，设原有种植面积为 $x$ hm²，则 $1333>18x$，也可以表示为 $18x<1333$。

**例题**

思考提示：逐句找出关键词“大于”“负数”“超过”，把它们转化为不等号，再设未知数列式。


```answer

   依据：“大于”对应符号“>”。
2. $b$ 的一半表示为 $\frac{b}{2}$，与3的差表示为 $\frac{b}{2}-3$，负数是小于0，所以 $\frac{b}{2}-3<0$。
   依据：“负数”即小于0。
3. 设原有猕猴桃种植面积为 $x$ hm²，18倍为 $18x$，1333超过 $18x$，所以 $1333>18x$，也可写成 $18x<1333$。
   依据：“超过”表示大于，交换两边后不等号方向改变。

答案：(1) $a+15>27$；(2) $\frac{b}{2}-3<0$；(3) $1333>18x$（或 $18x<1333$）。

易错提醒：“负数”是小于0，不要写成“≤0”；“超过”是严格大于，不要写成“≥”。
```

#### 11.1.2 不等式的解、解集与数轴表示

> 当不等式中的字母表示未知数时，经常需要求出未知数应取哪些值。例如对于不等式 $2x>210$，我们需要了解满足条件的车速 $x$ 的值。

##### 不等式的解

当 $x=90$ 时，$2x=180$，不等式 $2x>210$ 不成立；当 $x=110$ 时，$2x=220$，不等式 $2x>210$ 成立。与方程的解类似，我们把使不等式成立的未知数的值叫作不等式的解。例如110是不等式 $2x>210$ 的解，而90不是。

##### 不等式的解集

一般地，一个含有未知数的不等式的所有的解，组成这个不等式的解集。例如 $x>105$ 是不等式 $2x>210$ 的解集。求不等式的解集的过程叫作解不等式。

##### 在数轴上表示解集

不等式的解集可以在数轴上直观表示。在表示边界值的点上画空心圆圈，表示解集不包含这个点所对应的数；画实心圆点，表示解集包含这个点所对应的数。例如 $x>105$ 在数轴上表示时，在105处画空心圆圈，方向向右。

**例题**

```answer
   依据：代入不等式左边计算。

   依据：不等式 $x+3>6$ 要求左边严格大于6。

   依据：只有使不等式成立的未知数的值才是解。
```

使不等式成立的未知数的值叫不等式的解；所有解组成解集；解不等式就是求解集；数轴上空心圆圈表示不包含边界值，实心圆点表示包含边界值。

#### 11.1.3 不等式的基本事实与性质

> 与解方程需要依据等式的性质一样，解不等式需要依据不等式的性质。为此，我们先来看一看不等式有什么性质。

##### 不等式的基本事实

与等式类似，关于不等式有以下两个基本事实：
(1) 交换不等式两边，不等号的方向改变：如果 $a>b$，那么 $b<a$。例如由 $5>x$，可得 $x<5$。
(2) 不等关系可以传递：如果 $a>b$，$b>c$，那么 $a>c$。

##### 不等式的性质1

通过用“>”或“<”填空并观察不等号方向是否改变，可以发现：不等式两边加（或减）同一个数（或式子），不等号的方向不变。即如果 $a>b$，那么 $a\pm c>b\pm c$。

##### 不等式的性质2和性质3

继续用具体数验证：不等式两边乘（或除以）同一个正数，不等号的方向不变；不等式两边乘（或除以）同一个负数，不等号的方向改变。
- 性质2：如果 $a>b$，$c>0$，那么 $ac>bc$（或 $\frac{a}{c}>\frac{b}{c}$）。
- 性质3：如果 $a>b$，$c<0$，那么 $ac<bc$（或 $\frac{a}{c}<\frac{b}{c}$）。

性质2和性质3的区别在于乘（或除以）的数是正数还是负数：正数不改变方向，负数改变方向。

**例题**

题目：已知 $a>b$，比较下列两个式子的大小，并说明依据：(1) $a+3$ 与 $b+3$；(2) $-2a$ 与 $-2b$。

思考提示：观察两个式子分别对 $a$ 和 $b$ 进行了什么运算，再选择对应的不等式性质。


```answer
1. 因为 $a>b$，两边同时加3，由不等式的性质1，得 $a+3>b+3$。
   依据：不等式两边加同一个数，不等号方向不变。
2. 因为 $a>b$，两边同时乘 $-2$，由不等式的性质3，得 $-2a<-2b$。
   依据：不等式两边乘同一个负数，不等号方向改变。

答案：(1) $a+3>b+3$；(2) $-2a<-2b$。

易错提醒：第(2)问乘的是负数，不等号必须改变方向，不能写成 $-2a>-2b$。
```

**易错点**

- 运用性质3时忘记改变不等号方向。
- 把不等式的基本事实“交换两边不等号方向改变”与性质1“加减同一个数方向不变”混淆。

**理解检查**

1. 已知 $p>q$，用“>”或“<”填空：$-5p$ ___ $-5q$。

```check-answer
参考答案：$-5p<-5q$，依据是不等式的性质3。
```

2. 已知 $m>n$，用“>”或“<”填空：$m-5$ ___ $n-5$。

```check-answer
参考答案：$m-5>n-5$，依据是不等式的性质1。
```

**本单元小结**

不等式有两个基本事实：交换两边方向改变，不等关系可传递；三条性质分别对应加减同一个数（方向不变）、乘除正数（方向不变）、乘除负数（方向改变）。

**知识关联**

- 前置知识：不等式的概念
- 后续知识：利用不等式的性质解不等式


#### 11.1.4 利用不等式的性质解不等式

> 对于某些简单的不等式，可以直接得出它们的解集，例如 $x+4>10$ 的解集是 $x>6$，$2x<6$ 的解集是 $x<3$。但是对于比较复杂的不等式，直接得出解集就比较困难，因此还要讨论怎样解不等式。

##### 何时用

当不等式不能直接看出解集时，需要利用不等式的性质逐步化简，最终化为 $x>m$ 或 $x<m$（$m$ 为常数）的形式。

##### 依据与步骤

解不等式要借助不等式的性质：
- 若不等式两边需要加（或减）同一个数，用性质1，不等号方向不变；
- 若不等式两边需要乘（或除以）同一个正数，用性质2，不等号方向不变；
- 若不等式两边需要乘（或除以）同一个负数，用性质3，不等号方向改变。

例如解 $x-7>26$，根据性质1，两边加7，得 $x>33$；解 $-4x>3$，根据性质3，两边除以 $-4$，不等号方向改变，得 $x<-\frac{3}{4}$。

##### 在数轴上表示解集

求出解集后，在数轴上表示：边界值处画空心圆圈或实心圆点，再画出方向。

**例题**

题目：利用不等式的性质解不等式 $-8x>10$，并在数轴上表示解集。

思考提示：要把 $x$ 的系数化为1，两边需要除以 $-8$。因为除数是负数，所以要用性质3，不等号方向改变。


```answer
1. 不等式两边同时除以 $-8$，得 $x<\frac{10}{-8}$。
   依据：两边除以同一个负数，依据不等式的性质3，不等号方向改变。
2. 化简 $\frac{10}{-8}$，得 $x<-\frac{5}{4}$。
   依据：约分化简。
3. 在数轴上表示：在 $-\frac{5}{4}$ 处画空心圆圈，方向向左。
   依据：解集不包含 $-\frac{5}{4}$，且小于 $-\frac{5}{4}$ 的数在左侧。

答案：$x<-\frac{5}{4}$，数轴上在 $-\frac{5}{4}$ 处画空心圆圈并向左。

易错提醒：两边除以 $-8$ 时，不等号必须由“>”变为“<”，不能忘记改变方向。
```

**易错点**

- 解不等式时只做除法运算，忘记根据除数的正负判断是否改变不等号方向。
- 在数轴上表示解集时，把空心圆圈和实心圆点用错。

**理解检查**

1. 解不等式 $x+5>-1$，并在数轴上表示解集。

```check-answer
参考答案：$x>-6$，数轴上在 $-6$ 处画空心圆圈并向右。
```

2. 解不等式 $4x<3x+5$。

```check-answer
参考答案：两边减 $3x$，得 $x<5$。
```

**本单元小结**

解不等式就是利用不等式的性质逐步化为 $x>m$ 或 $x<m$ 的形式；加减同一个数用性质1，乘除正数用性质2，乘除负数用性质3且必须改变不等号方向；最后可在数轴上表示解集。

**知识关联**

- 前置知识：不等式的性质1、不等式的性质2、不等式的性质3、在数轴上表示不等式的解集

### 11.2 一元一次不等式

#### 11.2.1 一元一次不等式的概念与移项

> 与学习方程后重点研究一元一次方程类似，本节研究一类简单的不等式——一元一次不等式，探索它的解法，并用它解决实际问题。

##### 一元一次不等式的概念

观察下面的不等式：

$$x-7>26,\quad 3x<2x+1,\quad \frac{2}{3}x>50,\quad -4x>3.$$

可以发现，上述每个不等式都只含有一个未知数，且含有未知数的式子都是整式，未知数的次数是1。类似于一元一次方程，只含有一个未知数，且含有未知数的式子都是整式，未知数的次数是1的不等式，叫作一元一次不等式。

判断时要注意三个条件同时满足：只含一个未知数；含有未知数的式子都是整式；未知数的次数是1。

##### 解不等式中的移项

在解不等式 $x-7>26$ 时，根据不等式的性质1，不等式两边加7，不等号的方向不变，得

$$x-7+7>26+7,$$

即

$$x>26+7.$$

这一过程相当于把不等式 $x-7>26$ 左边的项“$-7$”，变号为“$+7$”后移到右边。这就是说，解不等式时也可以“移项”，即把不等式一边的某项变号后移到另一边，而不等号的方向不变。移项的依据是不等式的性质1，移项时只改变项的符号，不改变不等号方向。

**例题**

题目：解不等式 $x-7>26$。

思考提示：利用不等式的性质1，在不等式两边同时加7，使左边只剩未知数 $x$。


```answer
1. 不等式两边加7，得 $x-7+7>26+7$。
   依据：依据不等式的性质1，不等式两边加同一个数，不等号方向不变。
2. 化简得 $x>26+7$，即 $x>33$。
   依据：左边 $-7+7=0$，右边合并得33。

答案：$x>33$。

易错提醒：移项时要把该项变号，但不等号方向不变；不要误以为移项要改变不等号方向。
```

**易错点**

- 认为含有未知数的式子有分式也可以是一元一次不等式，忽略“含有未知数的式子都是整式”这一条件。
- 移项时忘记变号，或错误地改变不等号方向。

**理解检查**

1. 下列不等式是一元一次不等式吗？$3x<2x+1$。

```check-answer
参考答案：是，只含一个未知数 $x$，含有未知数的式子都是整式，未知数的次数是1。
```

2. 解不等式 $x-7>26$ 时，移项后得到什么？

```check-answer
参考答案：$x>26+7$，即 $x>33$。
```

**本单元小结**

一元一次不等式需同时满足：只含一个未知数、含有未知数的式子都是整式、未知数的次数是1。解不等式时可以移项，移项要变号，但不等号方向不变，依据是不等式的性质1。

**知识关联**

- 后续知识：解一元一次不等式的一般步骤


#### 11.2.2 解一元一次不等式的一般步骤与数轴表示

> 一般地，利用不等式的性质，采取与解一元一次方程类似的步骤，就可以求出一元一次不等式的解集。

##### 解一元一次不等式的一般步骤

解一元一次不等式，要依据不等式的性质，将不等式逐步化为 $x<m$（$x\le m$）或 $x>m$（$x\ge m$）的形式。常用步骤包括：去分母、去括号、移项、合并同类项、系数化为1。每一步都要依据不等式的性质，特别是系数化为1时，如果两边乘或除以同一个负数，不等号方向要改变。

##### 在数轴上表示解集

解一元一次不等式后，可以在数轴上表示其解集。数轴表示能直观呈现解集的范围。

**例题**

题目：解不等式 $10x-5(20-x)>90$。

思考提示：先去括号，再移项、合并同类项，最后系数化为1，将不等式化为 $x>m$ 的形式。


```answer
1. 去括号，得 $10x-100+5x>90$。
   依据：依据分配律和去括号法则展开。
2. 移项，合并同类项，得 $15x>190$。
   依据：将含 $x$ 的项合并，常数项移到右边，移项变号。
3. 系数化为1，得 $x>\frac{190}{15}$，即 $x>12\frac{2}{3}$。
   依据：两边同除以15，15为正数，不等号方向不变。

答案：$x>12\frac{2}{3}$。

易错提醒：系数化为1时，若两边除以负数，不等号方向必须改变；本题除以正数15，方向不变。
```

**易错点**

- 去括号时漏乘项或符号出错。
- 系数化为1时，两边除以负数忘记改变不等号方向。
- 在数轴上表示解集时，分不清实心点与空心点。

**理解检查**

1. 解不等式 $3(2x+5)>2(4x+3)$ 时，去括号后得到什么？

```check-answer
参考答案：$6x+15>8x+6$。
```

2. 解不等式 $-3x+2\ge -4$ 时，移项得 $-3x\ge -6$，两边都除以 $-3$ 后应得到什么？

```check-answer
参考答案：$x\le 2$，因为两边除以负数，不等号方向改变。
```

**本单元小结**

解一元一次不等式的一般步骤是去分母、去括号、移项、合并同类项、系数化为1，目标是把不等式化为 $x<m$（$x\le m$）或 $x>m$（$x\ge m$）的形式。系数化为1时若乘除负数，不等号方向要改变。解集可以在数轴上表示。

**知识关联**

- 前置知识：一元一次不等式的概念、解一元一次不等式中的移项
- 后续知识：用一元一次不等式解决实际问题


#### 11.2.3 用一元一次不等式解决实际问题

> 与用一元一次方程解决实际问题类似，通过用不等式表示实际问题中的不等关系，可以把实际问题转化为数学问题，进而通过解不等式得到实际问题的答案。

##### 用一元一次不等式解决实际问题

与用一元一次方程解决实际问题类似，通过用不等式表示实际问题中的不等关系，可以把实际问题转化为数学问题，进而通过解不等式得到实际问题的答案。

一般过程：分析问题中的不等关系；设未知数；列不等式；解不等式；根据实际意义确定答案。列不等式时，要抓住关键词如“超过”“不小于”“至多”“至少”等，将其转化为不等号。解出数学解集后，还要检查未知数在实际问题中的取值范围（如人数、题数应为正整数），确定符合实际意义的答案。

**例题**

题目：七年级举办古诗词知识竞赛，共有20道题，每一题答对得10分，答错或不答都扣5分。如果规定初赛成绩超过90分晋级决赛，那么至少要答对多少道题才能成功晋级？

思考提示：“初赛成绩超过90分”是问题中蕴含的不等关系，可以根据这个不等关系列出不等式。设答对 $x$ 道题，则答错或不答 $20-x$ 道，总得分为 $10x-5(20-x)$。


```answer
1. 设初赛答对了 $x$ 道题。
   依据：用未知数表示答对题数。
2. 根据“初赛成绩超过90分”列不等式 $10x-5(20-x)>90$。
   依据：答对得 $10x$ 分，答错或不答扣 $5(20-x)$ 分，总成绩超过90分。
3. 去括号，得 $10x-100+5x>90$。
   依据：展开括号。
4. 移项，合并同类项，得 $15x>190$。
   依据：合并含 $x$ 的项，常数项移到右边。
5. 系数化为1，得 $x>12\frac{2}{3}$。
   依据：两边同除以15，不等号方向不变。
6. 由 $x$ 应为正整数，可得 $x$ 至少为13。
   依据：答对题数必须是正整数，且要满足 $x>12\frac{2}{3}$，所以最小正整数为13。

答案：初赛至少要答对13道题才能成功晋级。

易错提醒：解出 $x>12\frac{2}{3}$ 后不能直接写 $x>12\frac{2}{3}$ 作为最终答案，必须结合“答对题数为正整数”确定最小整数。
```

**易错点**

- 列不等式时把“超过90分”误列为“不低于90分”或“等于90分”。
- 求出数学解集后忽略实际意义，没有根据正整数等条件确定最终答案。

**理解检查**

1. 用不等式表示“$4x$ 与7的和不小于6”。

```check-answer
参考答案：$4x+7\ge 6$。
```

2. 某问题解不等式得 $x>12\frac{2}{3}$，且 $x$ 表示答对题数，则 $x$ 的最小整数值是多少？

```check-answer
参考答案：13。
```

**本单元小结**

用一元一次不等式解决实际问题的关键是分析不等关系，设未知数、列不等式、解不等式，并根据实际意义确定答案。数学解集要结合实际背景（如正整数）确定最终结果。

**知识关联**

- 前置知识：解一元一次不等式的一般步骤

### 11.3 一元一次不等式组

#### 11.3.1 从实际问题引入一元一次不等式组

> 教材通过抽污水问题引入：某工程队用每小时可抽30t水的抽水机抽污水，估计积存污水超过1200t而不足1500t，求抽完所用时间的范围。

##### 为什么需要不等式组

一个不等式只能表示一个不等关系。当一个问题中含有多个不等关系时，就需要把几个不等式合起来表示。教材中的抽污水问题中，时间 \(x\) 同时满足两个条件：

\[
\begin{cases}
30x>1200,\\
30x<1500.
\end{cases}
\]

##### 一元一次不等式组的概念

类似于方程组，把两个含有同一个未知数的一元一次不等式合起来，组成一个一元一次不等式组。例如上面的不等式组中，两个不等式都含未知数 \(x\)，且都是一元一次不等式。

##### 从实际问题到不等式组

设用 \(x\) h 将污水抽完。由“超过1200t”得 \(30x>1200\)；由“不足1500t”得 \(30x<1500\)。解这两个不等式，得 \(x>40\) 与 \(x<50\)。把解集在数轴上表示，公共部分是 \(40<x<50\)。因此抽完所用时间多于40h而少于50h。

##### 解不等式组的含义

不等式组中各不等式解集的公共部分，就是不等式组中 \(x\) 的取值范围。解不等式组就是求它的解集。

**例题**

题目：某工程队用每小时可抽30t水的抽水机来抽污水管道里积存的污水，估计积存的污水超过1200t而不足1500t，求将污水抽完所用时间的范围。

思考提示：设抽完污水所用时间为 \(x\) h，根据“超过1200t”和“不足1500t”列出两个不等式，组成不等式组，再求解集。


```answer
1. 设用 \(x\) h 将污水抽完。
   依据：用未知数表示所求的时间范围。
2. 根据污水超过1200t，得 \(30x>1200\)；根据污水不足1500t，得 \(30x<1500\)。
   依据：把两个不等关系分别用不等式表示。
3. 组成不等式组 \(\begin{cases}30x>1200,\\30x<1500.\end{cases}\)
   依据：两个不等式含有同一个未知数，合起来组成一元一次不等式组。
4. 解不等式①得 \(x>40\)，解不等式②得 \(x<50\)。
   依据：分别求出每个不等式的解集。
5. 在数轴上表示两个解集，公共部分为 \(40<x<50\)。
   依据：不等式组的解集是各不等式解集的公共部分。

答案：抽完所用时间多于40h而少于50h，即 \(40<x<50\)。

易错提醒：注意“超过”对应 \(>\)，“不足”对应 \(<\)，不要漏掉等号或方向写反；解集要取公共部分，而不是分别写两个不等式。
```

**易错点**

- 认为一元一次不等式组中的不等式可以含有不同未知数；教材强调“含有同一个未知数”。
- 把两个不等式的解集直接并列写出，而不取公共部分。

**理解检查**

1. 什么是一元一次不等式组？

```check-answer
参考答案：把两个含有同一个未知数的一元一次不等式合起来，组成一个一元一次不等式组。
```

2. 抽污水问题中，为什么时间 \(x\) 要同时满足 \(30x>1200\) 和 \(30x<1500\)？

```check-answer
参考答案：因为积存污水超过1200t而不足1500t，所以抽水量要同时大于1200t且小于1500t。
```

**本单元小结**

实际问题中若有多个不等关系，可设未知数后列出一元一次不等式组；不等式组的解集是各不等式解集的公共部分，并能解释实际问题的范围。

**知识关联**

- 后续知识：不等式组的解集与解不等式组、用数轴确定不等式组的解集


#### 11.3.2 不等式组的解集与用数轴确定解集

##### 解集的定义

一般地，几个不等式的解集的公共部分，叫作由它们所组成的不等式组的解集。解不等式组就是求它的解集。例如抽污水问题中，不等式组的解集是 \(40<x<50\)。

##### 数轴的作用

把不等式①和②的解集在同一条数轴上表示出来，就容易看出两个不等式解集的公共部分。教材指出：利用数轴可以直观地确定不等式组的解集。

##### 无解的情形

当各不等式的解集在数轴上没有公共部分时，不等式组无解。例如例1第(2)题解得 \(x\ge 8\) 与 \(x<45\)，在数轴上表示后没有公共部分，所以不等式组无解。

**例题**

题目：解不等式组 \(\begin{cases}2x-1>x+1,\\x+8<4x-1.\end{cases}\)

思考提示：先分别解每个不等式，再把解集表示在同一条数轴上，找公共部分。


```answer
1. 解不等式①：\(2x-1>x+1\)，得 \(x>2\)。
   依据：移项、合并同类项求出第一个不等式的解集。
2. 解不等式②：\(x+8<4x-1\)，得 \(x>3\)。
   依据：移项、合并同类项求出第二个不等式的解集。
3. 在数轴上表示 \(x>2\) 和 \(x>3\)，公共部分为 \(x>3\)。
   依据：不等式组的解集是各解集的公共部分，数轴可直观显示。

答案：不等式组的解集为 \(x>3\)。

易错提醒：在数轴上表示解集时，注意边界点是否包含；取公共部分时不要误取并集。
```

**易错点**

- 把不等式组的解集误认为各解集的并集。
- 在数轴上表示解集时，分不清实心点与空心点。

**理解检查**

1. 不等式组的解集是什么？

```check-answer
参考答案：几个不等式的解集的公共部分。
```

2. 解不等式组 \(\begin{cases}x\ge 8,\\x<45\end{cases}\) 的解集是什么？

```check-answer
参考答案：无解，因为两个解集没有公共部分。
```

**本单元小结**

不等式组的解集是各不等式解集的公共部分；用数轴表示各解集可以直观确定公共部分，若无公共部分则不等式组无解。

**知识关联**

- 前置知识：一元一次不等式组的概念
- 后续知识：解一元一次不等式组的一般步骤
- 相关知识：不等式组无解的情形


#### 11.3.3 解一元一次不等式组的一般步骤与整数解

##### 一般步骤

解一元一次不等式组时，一般先求出其中各不等式的解集，再求出这些解集的公共部分。利用数轴可以直观地确定不等式组的解集。

##### 求整数解

使两个不等式都成立的 \(x\) 的值，就是两个不等式的公共解。因此求出由这两个不等式组成的不等式组的解集，解集中的整数就是 \(x\) 可取的整数值。

例2中，解不等式组得 \(-\frac{5}{2}<x\le 4\)，所以 \(x\) 可取的整数值是 \(-2,-1,0,1,2,3,4\)。

**例题**

题目：\(x\) 取哪些整数值时，不等式 \(5x+2>3(x-1)\) 与 \(\frac{1}{2}x-1\le 7-\frac{3}{2}x\) 都成立？

思考提示：使两个不等式都成立的 \(x\) 就是两个不等式的公共解，因此组成不等式组，求其解集，再取整数。


```answer
1. 组成不等式组 \(\begin{cases}5x+2>3(x-1),\\\frac{1}{2}x-1\le 7-\frac{3}{2}x.\end{cases}\)
   依据：两个不等式都成立等价于求它们的公共解。
2. 解不等式组，得 \(-\frac{5}{2}<x\le 4\)。
   依据：分别解各不等式并取公共部分。
3. 在解集中取整数，得 \(-2,-1,0,1,2,3,4\)。
   依据：解集中的整数就是 \(x\) 可取的整数值。

答案：\(x\) 可取的整数值是 \(-2,-1,0,1,2,3,4\)。

易错提醒：注意解集端点 \(4\) 包含在内，所以 \(4\) 是整数解；\(-\frac{5}{2}\) 不包含，所以 \(-2\) 是大于 \(-\frac{5}{2}\) 的最小整数。
```

**易错点**

- 求整数解时忽略解集端点的开闭，多取或少取端点值。
- 把“都成立”理解为分别求两个不等式的整数解再合并。

**理解检查**

1. 解一元一次不等式组的一般步骤是什么？

```check-answer
参考答案：先求出其中各不等式的解集，再求出这些解集的公共部分，利用数轴直观确定。
```

2. 若不等式组的解集为 \(-\frac{5}{2}<x\le 4\)，则 \(x\) 可取的整数值有哪些？

```check-answer
参考答案：\(-2,-1,0,1,2,3,4\)。
```

**本单元小结**

#### 11.3.4 不等式组无解的情形

##### 无解的含义

当不等式组中各不等式的解集没有公共部分时，不等式组无解。教材例1第(2)题解得 \(x\ge 8\) 与 \(x<45\)，在数轴上表示后，两个解集没有公共部分，所以不等式组无解。

##### 判断方法

把各不等式的解集在同一条数轴上表示出来，观察是否存在公共部分；若没有公共部分，则不等式组无解。

**例题**

题目：解不等式组 \(\begin{cases}2x+3\ge x+11,\\\frac{2x+5}{3}-1<2-x.\end{cases}\)

思考提示：分别解两个不等式，在数轴上表示解集，观察是否有公共部分。


```answer
1. 解不等式①：\(2x+3\ge x+11\)，得 \(x\ge 8\)。
   依据：移项、合并同类项求出第一个不等式的解集。
2. 解不等式②：\(\frac{2x+5}{3}-1<2-x\)，得 \(x<45\)。
   依据：去分母、移项、合并同类项求出第二个不等式的解集。
3. 在数轴上表示 \(x\ge 8\) 和 \(x<45\)，没有公共部分。
   依据：数轴直观显示两个解集无交集。

答案：不等式组无解。

易错提醒：不要因为两个不等式都有解就认为不等式组一定有解；必须检查解集是否有公共部分。
```

**易错点**

- 认为每个不等式都有解集，不等式组就一定有解。
- 在数轴上误将两个解集的并集当作公共部分。

**理解检查**

1. 不等式组 \(\begin{cases}x\ge 8,\\x<45\end{cases}\) 有解吗？

```check-answer
参考答案：无解，因为两个解集没有公共部分。
```

2. 如何判断不等式组是否无解？

```check-answer
参考答案：把各不等式的解集在同一条数轴上表示出来，观察是否有公共部分；没有公共部分则无解。
```

**本单元小结**

不等式组无解当且仅当各不等式解集没有公共部分；用数轴表示各解集可以直观判断。

**知识关联**

- 前置知识：不等式组的解集与解不等式组、用数轴确定不等式组的解集

### 12.1 统计调查

#### 12.1.1 统计调查与全面调查

> 面对一个统计问题，首要任务是收集数据。例如，要了解全班同学对五类课外活动的喜爱情况，需要进行统计调查。

##### 为什么需要统计调查
统计的研究对象是数据。面对一个统计问题，首要的任务是收集数据，统计调查是收集数据的常用方法。

##### 全面调查
考察全体对象的调查叫作全面调查。例如，2020年我国进行的第七次全国人口普查，就是一次全面调查。

#### 12.1.2 抽样调查与样本

> 当调查对象数量较多时，全面调查花费时间长、消耗人力物力大，需要寻找一种不作全面调查就能了解整体情况的方法，这就是抽样调查。

##### 为什么需要抽样调查
全面调查需要对调查对象的全体进行调查。当总体包含的个体很多时，全面调查花费的时间长，消耗的人力、物力大。抽样调查只抽取一部分对象进行调查，然后根据调查数据推断全体对象的情况，可以达到既省时省力又能解决问题的目的。

##### 样本与样本容量
被抽取调查的那部分对象称为样本。一个样本中包含的个体的数目称为样本容量。例如，抽取100名学生进行调查，样本容量为100。

##### 简单随机抽样
在抽取样本的过程中，总体中的每一个个体都有相等的机会被抽到，像这样的抽样方法称为简单随机抽样。抽取样本时，不能偏向某些个体，应使总体中的每一个个体都有相等的机会被抽到。

```answer
4. 整理样本数据，用样本中各类课外活动的喜爱比例推断全校学生的情况。
   依据：抽样调查是根据样本数据推断全体对象的情况。

答案：可以采用抽样调查，抽取100名学生作为样本，用简单随机抽样保证每名学生被抽到的机会相等，然后根据样本数据推断全校学生对五类课外活动的喜爱情况。

易错提醒：样本容量不是样本中个体的数目吗？注意样本容量是一个数目，不带单位。抽取样本时不能偏向某些学生。
```

**易错点**

- 认为样本容量越大越好，忽略样本容量过大会失去省时省力的优势。
- 认为随便抽取一部分对象就是简单随机抽样，忽略“每个个体有相等机会被抽到”这一条件。

**理解检查**

1. 从全校2000名学生中抽取100名进行调查，样本和样本容量分别是什么？

```check-answer
参考答案：样本是被抽取的100名学生，样本容量是100。
```

2. 简单随机抽样中，总体中的每个个体被抽到的机会有什么关系？

```check-answer
参考答案：每个个体都有相等的机会被抽到。
```

**本单元小结**

抽样调查只抽取一部分对象进行调查，并根据样本数据推断总体；样本是被抽取调查的那部分对象，样本容量是样本中个体的数目；简单随机抽样要求每个个体有相等的机会被抽到。

**知识关联**

- 前置知识：统计调查与数据收集、全面调查、总体与个体
- 后续知识：全面调查与抽样调查的特点及选择


#### 12.1.3 全面调查与抽样调查的选择

> 全面调查和抽样调查各有特点，实际调查中需要根据具体情况选择合适的调查方式。

##### 全面调查的特点
全面调查收集到的数据全面、准确，但一般花费多、耗时长，而且某些调查不宜用全面调查。

##### 抽样调查的特点
抽样调查具有花费少、省时省力的特点，但抽取的样本是否具有代表性，直接关系到对总体估计的准确程度。

##### 如何选择
抽样调查适用于一些不宜用全面调查的情况，例如检测某批次灯泡的使用寿命等具有破坏性的调查。选择调查方式时，要根据调查目的和调查对象的特征，权衡数据的全面性、准确性与调查的花费、时间等因素。

**例题**

题目：下列调查中，哪些适宜用全面调查，哪些适宜用抽样调查？(1)了解全班同学的身高情况；(2)调查超市售卖的草莓农药残留是否超标；(3)选出学校短跑最快的学生参加全市比赛；(4)调查某批次汽车的抗撞击能力。

思考提示：根据全面调查和抽样调查的特点，结合调查目的和调查对象特征进行判断。


```answer
1. (1)了解全班同学的身高情况，适宜用全面调查。
   依据：全班人数有限，且需要准确了解每名同学的身高。
2. (2)调查超市售卖的草莓农药残留是否超标，适宜用抽样调查。
   依据：检测农药残留可能具有破坏性，且超市草莓数量大，全面调查花费大。
3. (3)选出学校短跑最快的学生参加全市比赛，适宜用全面调查。
   依据：需要准确找出跑得最快的学生，不能遗漏。
4. (4)调查某批次汽车的抗撞击能力，适宜用抽样调查。
   依据：抗撞击能力检测具有破坏性，不宜全面调查。

答案：(1)全面调查；(2)抽样调查；(3)全面调查；(4)抽样调查。

易错提醒：不能认为抽样调查一定比全面调查好，要根据调查目的和对象特征选择。
```

**易错点**

- 认为抽样调查总是比全面调查好，忽略样本代表性对估计准确程度的影响。
- 认为所有调查都适合用全面调查，忽略具有破坏性的调查不宜用全面调查。

**理解检查**

1. 检测某批次灯泡的使用寿命，适宜用哪种调查方式？为什么？

```check-answer
参考答案：适宜用抽样调查，因为检测灯泡使用寿命具有破坏性，不宜全面调查。
```

2. 抽样调查的样本代表性对总体估计有什么影响？

```check-answer
参考答案：抽取的样本是否具有代表性，直接关系到对总体估计的准确程度。
```

**本单元小结**

全面调查数据全面、准确但花费多、耗时长，某些调查不宜使用；抽样调查花费少、省时省力，但样本代表性影响估计准确程度。应根据调查目的和对象特征选择调查方式。

**知识关联**

- 前置知识：全面调查、抽样调查、样本与样本容量、简单随机抽样

### 12.2 用统计图描述数据

#### 12.2.1 选择统计图描述数据

> 对于收集到的统计数据，在对它们进行整理的基础上，往往需要根据问题的特点，选择合适的统计图描述数据，直观形象地反映数据的特征和其中蕴含的信息，从而解决相应的问题。

##### 为什么需要选择统计图
收集到的统计数据经过整理后，为了直观形象地反映数据的特征和其中蕴含的信息，需要根据问题的特点选择合适的统计图。

##### 如何选择
教材例1中，要表示公司60名员工中各类别体重指数的人数和所占百分比：
- 为了清楚地表示各类别中的人数，可以绘制条形图；
- 为了直观地表示各类别中的人数所占的百分比，可以绘制扇形图。

选择统计图时，应关注问题要突出的是“人数”还是“百分比”等数据特征。

**例题**

题目：某公司随机抽取60名员工，统计得到各类别体重指数的人数：体重过低10人，体重正常38人，超重7人，肥胖5人。请选择合适的统计图表示各类别的人数和所占百分比。

思考提示：问题要求同时表示人数和百分比。人数适合用条形图清楚表示；百分比适合用扇形图直观表示。


```answer
1. 统计各类别的人数和百分比，填入表格。
   依据：先整理数据，为画图提供依据。
2. 绘制条形图表示各类别的人数。
   依据：条形图能清楚地表示各类别中的人数。
3. 绘制扇形图表示各类别人数所占的百分比。
   依据：扇形图能直观地表示各部分占总体的百分比。

答案：可同时绘制条形图和扇形图：条形图表示各类别的人数，扇形图表示各类别人数所占的百分比。

易错提醒：不要只画一种图而忽略问题对“人数”和“百分比”两方面的要求。
```

**易错点**

- 认为任何统计图都能同样好地表示所有数据特征，忽视问题特点。
- 在需要表示百分比时误选条形图，或在需要比较人数时误选扇形图。

**理解检查**

1. 要直观表示各类别中的人数所占的百分比，应选择哪种统计图？

```check-answer
参考答案：扇形图。
```

2. 要清楚地表示各类别中的人数，应选择哪种统计图？

```check-answer
参考答案：条形图。
```

**本单元小结**

选择统计图应依据问题的特点：条形图便于清楚表示各类别人数，扇形图便于直观表示各部分占总体的百分比。

**知识关联**

- 后续知识：扇形图的画法


#### 12.2.2 扇形图的画法

> 在小学，我们学习过画条形图、折线图描述数据，并认识了扇形图。上一节中通过扇形图直观描述了全班同学或全校同学喜爱各类课外活动的情况，你知道上一节中的扇形图是如何画出来的吗？

##### 扇形图的含义
扇形图用圆代表总体，每一个扇形代表总体中的一部分，通过扇形的大小反映各个部分占总体的百分比。

##### 画法的依据
由于在一个圆内，扇形的大小由它的圆心角确定，因而只要根据各部分占总体的百分比求出圆心角的度数，就可以画出各部分对应的扇形。

##### 计算公式
\[\text{圆心角度数}=360^\circ\times\text{百分比}\]

##### 画图步骤
1. 按各类所占的百分比，计算对应扇形的圆心角度数；
2. 根据各圆心角的度数，在一个圆中画出各个扇形；
3. 注明各类别的名称及其相应的百分比。

例如，教材中“文学”对应扇形的圆心角为\(360^\circ\times13\%\approx47^\circ\)，其他类别同样计算后画出扇形图。

**例题**

题目：某班喜爱各类课外活动的百分比为：文学13%，科技约18%，体育约32%，艺术约27%，劳技10%。画出对应的扇形图。

思考提示：先由百分比计算各扇形圆心角，再在一个圆中按圆心角画出扇形，并标注名称和百分比。


```answer
1. 计算“文学”对应圆心角：\(360^\circ\times13\%\approx47^\circ\)。
   依据：扇形大小由圆心角确定，需先由百分比求圆心角。
2. 同样计算其他类别圆心角：科技约65°，体育约115°，艺术约97°，劳技约36°。
   依据：各部分都要按百分比求出对应圆心角。
3. 在一个圆中按各圆心角画出各个扇形。
   依据：圆心角决定扇形大小。
4. 注明各类别名称及其相应百分比。
   依据：使扇形图能清楚表达各类别及其占比。

答案：按计算出的圆心角画出各扇形，并标注名称和百分比，即得扇形图。

易错提醒：圆心角计算要用360°乘以百分比，不能直接用百分比当作角度。
```

**易错点**

- 把百分比直接当作圆心角度数。
- 画完扇形后忘记注明各类别名称和百分比。

**理解检查**

1. 某部分占总体的百分比为25%，其对应扇形圆心角是多少度？

```check-answer
参考答案：\(360^\circ\times25\%=90^\circ\)。
```

2. 扇形图中扇形的大小由什么确定？

```check-answer
参考答案：由扇形的圆心角确定。
```

**本单元小结**

扇形图用圆代表总体，扇形大小由圆心角决定；圆心角度数等于360°乘以百分比，据此画出各扇形并注明名称和百分比。

**知识关联**

- 前置知识：选择合适的统计图描述数据


#### 12.2.3 频数分布直方图的概念与画法

> 为了举办运动会，学校准备从七年级学生中挑选身高接近的40人组成入场式仪仗队。有63人报名参加选拔，他们的身高数据如表12.2-4所示。

##### 频数与组距
对落在各个小组内的数据进行累计，得到各个小组内的数据的个数叫作频数。组距是指每个小组的两个端点之间的距离（范围）。

##### 频数分布直方图
频数分布直方图是以小长方形的面积来反映数据落在各个小组内的频数的大小，小长方形的高是频数与组距的比值。
\[\text{小长方形面积}=\text{组距}\times\frac{\text{频数}}{\text{组距}}=\text{频数}\]
等距分组时，各小长方形的面积（频数）与高的比是常数（组距），因此画等距分组的频数分布直方图时，通常直接用小长方形的高表示频数。

##### 画频数分布直方图的步骤
1. 计算最大值与最小值的差；
2. 决定组距和组数；
3. 列频数分布表；
4. 画出频数分布直方图。

##### 组距和组数的确定
组距和组数的确定没有固定的标准，要凭借经验和所研究的具体问题来决定。将一批数据分组，一般数据越多，分的组数也越多。当数据在100个以内时，按照数据的多少，常分成5～12组。

例如，身高数据中最大值是172，最小值是149，差为23；若取组距为3，则\(\frac{23}{3}=7\frac{2}{3}\)，所以分成8组，组距和组数分别为3和8。

| 分组 | 频数 |

| 149≤x<152 | 2 |
| 152≤x<155 | 6 |
| 155≤x<158 | 12 |
| 158≤x<161 | 19 |
| 161≤x<164 | 10 |
| 164≤x<167 | 8 |
| 167≤x<170 | 4 |
| 170≤x<173 | 2 |

**例题**

题目：63名报名学生的身高数据中，最大值为172，最小值为149。若取组距为3，应分成多少组？并说明画频数分布直方图的一般步骤。

思考提示：先求最大值与最小值的差，再用差除以组距确定组数；然后列频数分布表并画直方图。


```answer
1. 计算最大值与最小值的差：\(172-149=23\)。
   依据：确定数据的变化范围。
2. 计算\(\frac{23}{3}=7\frac{2}{3}\)，因此分成8组。
   依据：组数需覆盖整个范围，不足一组也要算一组。
3. 列频数分布表，累计各小组内的数据个数。
   依据：得到各组的频数。
4. 画出频数分布直方图。
   依据：直观表示频数分布情况。

答案：分成8组，组距为3；步骤为：计算最大值与最小值的差、决定组距和组数、列频数分布表、画出频数分布直方图。

易错提醒：组数计算时不能把\(7\frac{2}{3}\)直接取7组，否则不能覆盖全部数据。
```

**易错点**

- 认为组距和组数有固定标准，忽视根据具体问题确定。
- 在等距分组直方图中误以为小长方形的高在任何情况下都直接表示频数，忽略其前提是等距分组。

**理解检查**

1. 频数分布直方图中小长方形的面积表示什么？

```check-answer
参考答案：表示数据落在相应小组内的频数。
```

2. 数据在100个以内时，常分成多少组？

```check-answer
参考答案：常分成5～12组。
```

**本单元小结**

频数分布直方图用小长方形面积反映频数；画图步骤为计算极差、决定组距和组数、列频数分布表、画直方图；组距和组数需根据具体问题确定。

**知识关联**

- 前置知识：选择合适的统计图描述数据
- 相关知识：扇形图的画法


#### 12.2.4 趋势图及其画法

> 在现实生活中，许多数据是与时间有关的，因此这些数据会呈现发展趋势。初中阶段的学生应能够理解报刊、图书中这类数据的表达，包括表格、描点、折线图、趋势图等，并尝试自己表达分析。

##### 趋势图的概念
用一条线（直线或曲线）来描述一个量与另一个量之间关系的统计图，叫作趋势图。

##### 趋势图的特点与作用
趋势图比较清楚地表示了两个量之间的关系，有利于根据一个量的变化，预测另一个量的变化趋势。例如，根据图12.2-13中的趋势图，可以预测当一天的最高气温为30℃时，饮品店卖出的冷饮约为155杯。

##### 画趋势线的方法
要画出“尽可能靠近所有散点的直线”，可以有很多种画法。例如：
- 让直线经过尽可能多的点；
- 让直线两侧的点的个数大致相等；
- 画出多条直线，然后测量各点到这些直线的距离和，选取距离和最小的直线作为所求的直线。
这些画法都有一定的道理。

| 12 | 50 |
| 13 | 69 |
| 17 | 74 |
| 19 | 90 |
| 20 | 108 |
| 22 | 97 |
| 24 | 119 |
| 25 | 125 |
| 28 | 154 |

**例题**

题目：根据散点图，要画出一条“尽可能靠近所有散点的直线”，可以有哪些画法？

思考提示：趋势线要尽可能靠近所有散点，可从经过点数、两侧点数、距离和等角度考虑。


```answer
1. 让直线经过尽可能多的点。
   依据：使直线贴近多数数据点。
2. 让直线两侧的点的个数大致相等。
   依据：使直线在点群中间，平衡两侧偏差。
3. 画出多条直线，测量各点到这些直线的距离和，选取距离和最小的直线。
   依据：距离和最小表示直线整体上最接近所有散点。

答案：可让直线经过尽可能多的点；让直线两侧点的个数大致相等；或选取各点到直线距离和最小的直线。

易错提醒：趋势线不要求经过所有点，而是尽可能靠近所有散点。
```

**易错点**

- 认为趋势线必须经过每一个散点。
- 把趋势图与折线图混为一谈，忽视趋势图用于表示两个量之间的关系并预测趋势。

**理解检查**

1. 趋势图的主要作用是什么？

```check-answer
参考答案：比较清楚地表示两个量之间的关系，有利于根据一个量的变化预测另一个量的变化趋势。
```

2. 画趋势线时，选取距离和最小的直线有什么道理？

```check-answer
参考答案：使直线整体上尽可能靠近所有散点。
```

**本单元小结**

趋势图用一条线描述两个量之间的关系，可用于预测变化趋势；画趋势线有多种方法，目标都是使直线尽可能靠近所有散点。
