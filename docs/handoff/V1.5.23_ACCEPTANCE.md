## 2. 具体实现

**前端 `TeacherAnalytics.tsx`**
- 删除 `应作答组合数`、`无法确定应答范围`、`应作答`/`无法确定`列，以及“应作答无法确定”说明。
- 班级比较：
  - 侧栏标题改为“班级差异说明”，输出 `A班 X% vs B班 Y%，差 +Zpp`。
  - 删除 `sample_warning`、`coverage_warning` 和“样本不足”卡片。
- 错误类型：
  - 表头“加权次数”→“实际次数”；
  - 使用 `actual_count`；
  - 删除“班级”列；
  - 未归因错误不进入主表，脚注显示 `另有 N 条模型未给出可归因类型的错误未计入上表`。
- 学生画像删除模型/提示词/证据版本行。
- 班级学情新增两个卡片：
  - 共性问题：知识点均值、薄弱人数/有效人数、薄弱率；
  - 差异问题：均值、标准差、最高-最低分差、有效人数。

**后端 `learning_analysis.py`**
- `class_profile` 生成 `class_summary`：
  - 共性问题：有效学生≥3，按薄弱率/均值排序；
  - 差异问题：有效学生≥3，按标准差/最高-最低分差排序；
  - 不把证据不足当 0 分。
- 班级题目过滤：只保留本班 `answered/expected/...` 大于 0 的题目。
- `question_performance` 在指定班级时过滤 0 作答题目。
- 对比 note 删除“样本不足”措辞。

**后端 `xueban_teacher.py`**
- `/analysis/errors` 和总览错误聚合：
  - 实际次数 `actual_count` 来自错误证据条数；
  - 排除“未识别错误”，单独返回 `unrecognized_error_count`；
  - 排序按实际次数。
- 分析缓存版本 `analysis-v2`→`analysis-v3`，避免旧缓存继续返回 Q038/旧错误表。

## 5. 未改变/未完成

- 没有降低 `MIN_EVIDENCE`、`MIN_QUESTIONS`、`MIN_COVERAGE`。
- 没有把未识别错误强行归入某个类型；只是从类型表移出并单独计数。
- “实际次数”按错误证据条数；同一学生同一题多个步骤可产生多条，和“人数”不是同一单位。
- 班级比较仍只对两班都有有效均值的知识点做差值；无证据知识点不参与差值。
