## 7. 未完成 / 未验证（必须如实标注）

1. **真实模型重判未执行**：本环境没有 `DEEPSEEK_API_KEY`，117 条契约违规只做了「如实失败」，没有重新调用模型。需要 Key + 额度授权后跑小批验收。
2. **真实模型判题质量未评测**：`error_label_gold=0`，没有 precision/recall 真值。
3. **错误分类的异步进度/重试**未实现：现有 `/error-labels/classify` 是同步规则分类，幂等（已有标签不重复写），但没有任务进度面板。
4. **知识依赖图预构建**未实现：仍在「进入页面时生成候选边」，没有在课程解析/题目预处理阶段统一建图。
5. **教师端 UI 只做了「统一」而不是「重做」**：`teacher.css` 已按学生端 token 重写（页头/卡片/面板/表格/按钮/表单/上传/空态/滚动条），任务列表与汇总计数也改为作答级；但没有逐页重排数据管理/判题中心的交互，也没有做全站组件化。
6. **`batch_305316cdd0` 去留未决**：它是同一套 CSV 的旧导入，与 `batch_a76e3dd0aa` 重复；未删除、未合并，等产品决策。
7. **性能仍偏高**：班级画像本地 0.70s、接口约 1.2–2.6s（含快照写入与序列化）；已从 3.4s 降到 0.7s，但没有做分页/增量。
8. **并发/压测未做**：多 worker 只做了 4 线程抢同一条的单元级验证。
9. **没有 pytest**：164 个历史模块仍无法运行（环境缺失，不是本次回归）。
