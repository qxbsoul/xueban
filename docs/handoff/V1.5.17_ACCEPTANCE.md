## 2. 审计发现的问题清单与根因

| # | 问题 | 根因（文件/函数） | 修复 |
|---|---|---|---|
| 1 | 26 条失败为 `float() argument must be … NoneType` | `validate_llm_result` 直接 `_number(result["score"])`；模型漏返回顶层 `score`，旧代码把空值当异常而非可修复项 | 顶层 score 缺失时用完整步骤分求和修复并留痕 `score_derived_from_steps`；仍失败则结构化 `score_type_error` 并重试一次 |
| 2 | 失败类型只有 11 类，历史全记成 `model_error` | `ERROR_TYPE_LABELS` / `classify_grader_error` 粒度不足；历史 attempt 只有原始文本 | 扩到 18 类；`GradeFailure(code, stage, message, detail)`；历史文本按 SSL/IncompleteRead/timeout/NoneType/满分规则反推分类 |
| 3 | 评分点满分声明高于原始满分即失败（117 条契约失败中的一部分） | `_validate_point_link` 对 `declared_max > original` 直接抛错 | 若 awarded ≤ 原始满分，把声明满分修回原始值并记 warning；awarded 超原始满分仍失败 |
| 4 | 契约/格式错误不重试，直接失败 | `call_grader_with_retry` 只重试网络 | 结构类错误（截断/非法 JSON/缺字段/契约/分数空值）在 `grade_answer` 内修复性重试一次 |
| 5 | `/analysis/tasks` 500 `unable to open database file` | SQLite 排序临时文件依赖系统 TEMP；Windows 沙箱 TEMP 不可写 | `xueban_store.conn()` 增加 `PRAGMA temp_store=MEMORY` |
| 6 | 单题重判成功后任务失败数不降 | `grade()` 只写新 grade，不更新 `teacher_grade_job_items` | 成功后把该作答的 failed item 改为 completed 并 `sync_job_counts`（历史 attempt 保留） |
| 7 | 重试会重置人工确认项 | `retry_job` 只按 `status='failed'` | SQL 排除最新 grade 为 `manual_corrected/manual_confirmed` 的项，返回 `skipped_manual` |
| 8 | LLM 分析只有批次级、无法跟随单题变化 | 旧 `teacher_analysis_tasks` 只有 batch/scope，无证据版本 | v7 增加 `object_type/object_id/evidence_version/prompt_version/model/superseded` 与事件表；按学生/班级生成 |
| 9 | 语义分析失败会覆盖旧结果 | 任务原地重建 | 新版本任务独立；旧任务标记 `superseded=1` 但保留结果；`latest_valid_llm` 只回退到有内容的结果 |
| 10 | 前端暴露分析状态与手动按钮 | `TeacherAnalytics.tsx` 的 `AnalysisStatusBar` | 删除状态条/刷新/重新生成入口；结果自动加载，运行中显示“生成中”，失败显示可恢复提示 |
| 11 | 班级选择用下拉框且与学生重复 | 右上角班级 select | 改为真实统计卡片网格；删除班级下拉 |
| 12 | 学生画像两个“请选择学生” | 顶部 select + 页面内 select | 改为分组学生条 → 详情；详情只保留返回入口；范围只有本次/全部 |
| 13 | 各子页面布局不一致 | 旧页面各自为政 | 统一 `.ta-main` 最大宽度、页头、卡片、表格、按钮、加载/空/错误态 |

## 5. 重试成功率与正确性

- 真实重判 3 次（同一作答 `D38-N02-Q043-r1`）：

## 9. 未解决 / 限制（真实原因）

1. **仍有 93 条历史失败**：28 SSL、27 响应中断、5 超时、3 断连需要真实网络环境重试；26 条分数空值可通过重判修复，但需要用户授权批量调用模型（本次只验证 1 条）。3 条满分不匹配 + 1 条契约需模型重新生成合法输出。
2. **历史 attempt 无堆栈/异常类**：旧版本只保存原始文本，无法补出 `exception_class`；新失败已保存 `exception_class` 与原始信息。
3. **语义分析按查看自动生成**：班级/学生首次查看会触发一次真实模型调用（约 20–30s）；没有独立任务队列，进程重启会回收 running 任务并在下次查看时重建。
4. **知识依赖边为空**：真实库没有已确认的前置关系；页面按主题展示知识点，不伪造依赖。
5. **人工修正仅改整题分时不产生评分点证据**：按既有业务规则，需要在评分点确认后才进入证据；页面会显示证据不足，这是正确行为。
6. **24 小时/长期任务**：未做定时重跑；分析任务由判题/人工修改事件触发。
