# v1.5.11 验收报告

- 基线：v1.5.10 `be74df5`
- 目标版本：v1.5.11（提交见 `git log -1`）
- 验收方式：代码审查 + 隔离临时库测试 + 真实数据库副本 + 真实启动浏览器验收 + 只读真实样本导出

## 1. 修改概览

| 问题 | 根因 | 修改 | 影响旧数据 |
| --- | --- | --- | --- |
| 游客被当教师 | guest 未写 role；`teacher()` 默认 teacher | 显式 guest + 严格白名单 + 迁移 v4 | 46 个真实游客账号将在启动时降级；教师/学生不变 |
| 跨教师越权 | 任务无归属，查询全局 | `owner_id` + 归属中间件 + 列表/详情/默认批次按教师过滤 | 历史无主任务保持共享可见 |
| 趋势误判可比 | 只检查版本非空 | 版本值必须一致或显式兼容；逐题版本；算法版本 | 旧快照保留；新签名按 v3 |
| 方法覆盖恒 100% | 分母来自同一集合 | 独立机会表 + 空值语义 | 旧数据方法机会为 0，显示暂不可计算 |
| 同编号身份混淆 | 全局学生表 | 任务内 enrollment 快照 + 身份状态 | 迁移 v5 回填 40 条 unverified |
| 映射不可追溯 | 无拒绝/版本 | 拒绝、版本、影响面、判题/快照记录版本 | 旧判题 mapping_version 为 NULL |
| 分类无评价 | 无人工真值 | gold 表 + P/R/F1 接口 | 不影响历史标签 |
| 推荐无反馈 | 只有推荐规则 | 反馈表 + 创建/完成/查询 | 无 |
| 后台恢复未验证 | 逻辑在 bootstrap 内 | 抽出 `recover_stale_jobs` + 并发测试 | 无 |

修改模块：

- Python：`xueban/api/xueban_teacher.py`、`xueban/api/xueban_auth.py`、`xueban/server.py`、`xueban/services/learning_analysis.py`。
- 前端：`LearningAnalytics.tsx`、`AnalyticsExtras.tsx`、`StudentAnalytics.tsx`。
- 脚本：`scripts/export_grading_sample.py`、`verify-v1.5.11.mjs`、`verify-v1.5.11-extra.mjs`。
- 测试：新增 6 个测试模块（权限、趋势版本、方法机会、身份映射、反馈指标、后台可靠性）与 6 个 worker。

## 2. 数据库变化

新表：`teacher_enrollments`、`teacher_method_opportunities`、`teacher_mapping_versions`、`teacher_version_compat`、`recommendation_feedback`、`error_label_gold`。

新列：`teacher_batches.owner_id`、`teacher_grade_runs.mapping_version`、`teacher_analysis_runs.mapping_version`。

新索引：`teacher_batches(owner_id,created_at)`、`teacher_enrollments(batch_id,student_id)`、`teacher_enrollments(student_id)`、`teacher_method_opportunities(batch_id,method_id)`、`answer_error_labels(answer_id)`、`error_label_gold(batch_id)`、`recommendation_feedback(student_id,batch_id)`。

迁移：

- v4：`auth_type=guest` → `role=guest`；缺失角色按最小权限（student/guest）；每条写 `xueban_account_audit`。
- v5：从历史作答回填 `teacher_enrollments`，默认 `unverified`。

兼容性：只增表/列/索引，不删旧数据；旧代码忽略新对象。回滚：代码回滚后新对象保留；角色迁移回滚需按审计逐条人工处理，禁止批量改回 teacher。

## 5. 学情分析验收

### 趋势

| 场景 | 状态 | 结果 |
| --- | --- | --- |
| 版本完全一致 | comparable | 通过 |
| grading_rule_version 不同（g1/g2） | non_comparable | 原因含“grading_rule_version 不同且未验证兼容” |
| 登记兼容依据后 | comparable | 通过 |
| 缺版本元数据 | unverifiable | 通过 |
| 题集/满分/评分点/映射不同 | non_comparable | 通过 |
| 学生 1 人 vs 2 人 | comparable + 50% 重合率警告 | 通过 |

真实数据：N01 unverifiable（最早时间点），N02 non_comparable（28 vs 45 题）；前端只画两个不连线点，分别标注“缺少版本/不可比”。

### 身份与映射

- 两个任务同编号 → 两条 enrollment，均 unverified，班级不同；显式确认后才 same/distinct；跨任务趋势提示未确认。
- 删除任务 A → A 的 enrollment=0，B 保留 1。
- 映射确认 v1 → 拒绝 v2；历史含 confirm/reject；旧判题/旧快照被 impact 识别；映射版本变化必产生新快照。
