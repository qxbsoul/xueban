## 3. 评分点统一校验

实现：`_validate_point_link()`，reasoning_step 与 operation_unit 共用。

- ID 必须匹配 `QxxxPx` 且属于当前题目版本解析出的原始评分点。
- 原始评分点不可解析 → 直接拒绝，操作层不能绕过。
- `max_score` 必须等于原始满分，不信任模型自报上限。
- `awarded_score` 必须 `0..原始满分`。
- 同一评分点跨多个 operation：累计得分、evidence_count 增加，但只计一次总分且不超上限。
- 步骤层 + 操作层同时提供：
  - 操作层是唯一计分来源；
  - 步骤层仍逐条校验；
  - 两层分配不一致 → `step_links_ignored` review；一致则不误报。
- 部分 operation 无链接：至少一个 operation 有链接时，缺链接的 operation → `operation_without_scoring_point` review；全部 operation 无链接、由步骤层计分时不误报。
- 评分点合计 != 总分 → `scoring_points_do_not_close` review；未处置评分点单列。

测试：`test_scoring_knowledge.py` 中 8 个评分点用例（max 不一致、超原始上限、不可解析未知 ID、多点证据、双层链接、部分 operation 缺链接、总分不一致、多评分点闭合）。

## 4. 知识映射可信度

实现：`_normalize_knowledge_links()` + `aliases` + `confirmed_mappings`。

规范化规则：

```text
indicator id (indicator_i01) ─┐
indicator code (I01) ─────────┼─→ canonical code (I01)
kp:indicator id ──────────────┤
kp:indicator code ────────────┘
```

- 合法别名匹配同一条确认映射，不再被标记 `unknown_knowledge_point`。
- 不存在的知识点（如 `I99`、`kp:I99`）保留原值并记 review。
- `model_inferred` 强制 `pending`，即使模型声称 `teacher_confirmed`；不会因别名匹配升级。
- `existing_mapping` / `teacher_confirmed` 必须命中当前批次 `scoring_point_knowledge_links` 中 `status=confirmed` 且 `confirmed_by` 非空的真实记录，否则降级为 `model_inferred/pending` 并记 `mapping_claim_not_found`。
- `mapping_version` 由系统读取当前批次版本，模型传 999 也被忽略。
- 真实确认映射保留 `confirmed_by`、`confirmed_at`、`mapping_link_id`。

测试：`test_scoring_knowledge.py` 9 个知识点用例（合法三别名、未知、未知别名、伪造确认、伪造版本、真实确认、model_inferred 强制 pending、伪造 existing_mapping）。

## 5. 预检脚本复核

- 问题关联 key：`(student_id, event_id, revision, question_id)`，两学生同 event/revision/question 不会互相污染。
- Key 检测与 `default_llm_key()` 同源：环境变量 → 当前目录 `.env` → 后端 `.env`；只输出布尔值。
- 只读连接 `file:...?mode=ro`；测试比较运行前后 SHA-256 一致。
- 输出 `schema_migrations` 完成/缺失版本；未完成进入 `blocking_reasons`。
- 输出三态：`code=runnable`、`database=migrated|not_migrated`、`model=configured|not_configured`。
- 输出原始数据库绝对路径、batch_id、`checked_at`、`script_version=v1.5.14-preflight`。
- 需要复核的数据不会归入 `pending_direct`；有 review 问题进入 `pending_review`。

测试：`test_preflight_admission.py` 4 项（学生维度、`.env`/无 Key、迁移不完整阻断、SHA 不变）。
